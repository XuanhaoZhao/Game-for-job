# 贪吃蛇游戏

## 项目介绍
贪吃蛇游戏是一个经典的休闲游戏，玩家通过控制蛇的移动来吃掉食物，随着食物的增加，蛇的长度也会增加。

## 项目设置
直接打开 `index.html` 文件即可在浏览器中运行游戏。

## 技术栈
- 原生 JavaScript
- HTML5 Canvas
- CSS3
