# 项目概述

该项目集合包含两个经典游戏：Pacman Game 和 贪吃蛇游戏。每个游戏都展示了不同的前端技术和实现方式。

## 使用方法

- **Pacman Game**: 使用 Vue.js 构建，需通过 `npm install` 安装依赖后运行。
- **贪吃蛇游戏**: 使用原生 JavaScript 构建，直接打开 `index.html` 文件即可运行。

## 技术栈

- Vue.js 3
- JavaScript (ES6)
- HTML5 Canvas
- CSS3

## 未来规划

- **前端优化与现代化**: 将项目迁移到现代框架并使用 TypeScript。
- **后端集成**: 添加用户认证和排行榜功能。
- **性能优化**: 使用 Web Workers 和 WebGL 提升性能。
- **游戏功能扩展**: 添加多人模式和不同难度级别。
- **国际化**: 实现多语言支持，使用 i18n 库。
- **测试与质量保证**: 编写单元测试和集成测试，使用 Jest 或 Mocha。
- **Progressive Web App (PWA)**: 将游戏转换为 PWA，支持离线游戏和添加到主屏幕。
- **区块链集成**: 实现基于区块链的积分系统或者 NFT 奖励。
