# 游戏项目集合

## 项目介绍
该项目集合包含两个经典游戏：Pacman Game 和 贪吃蛇游戏。每个游戏都展示了不同的前端技术和实现方式。

## 使用方法
- **Pacman Game**: 使用 Vue.js 构建，需通过 `npm install` 安装依赖后运行。
- **贪吃蛇游戏**: 使用原生 JavaScript 构建，直接打开 `index.html` 文件即可运行。

## 技术栈
- Vue.js 3
- JavaScript (ES6)
- HTML5 Canvas
- CSS3
