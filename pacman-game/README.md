# pacman-game

## 项目介绍
Pacman Game 是一个基于 Vue.js 构建的经典吃豆人游戏。玩家控制吃豆人在迷宫中移动，躲避幽灵并吃掉所有豆子以获得高分。

## 项目设置Project setup
```
npm install
```

### Compiles and hot-reloads for development

```
npm run build
```

```
npm run lint
```

## 技术栈
- Vue.js 3
- JavaScript (ES6)
- HTML5 Canvas

## 未来规划
- **前端优化与现代化**: 将代码迁移到 TypeScript，提升类型安全性。
- **游戏功能扩展**: 添加更多关卡和难度设置。
- **性能优化**: 使用 Web Workers 处理复杂计算，避免阻塞主线程。
- **测试与质量保证**: 编写单元测试和集成测试，使用 Jest 或 Mocha。
- **国际化**: 实现多语言支持，使用 i18n 库。
